# Food Tracker

Calories and protein, logged fast. A personal iPhone web app (PWA): installs from Safari, works offline, keeps all data on the phone.

- `npm install`, `npm run dev` to run locally
- `npm test` runs the calculation, ranking, 7-day, parser and Open Food Facts tests
- Push to `main` to deploy to GitHub Pages

Barcode data from [Open Food Facts](https://world.openfoodfacts.org) (ODbL). Generic food values based on UK reference data (CoFID, Open Government Licence).
